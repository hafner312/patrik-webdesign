# LUNARIS — Musterprojekt

Musterprojekt für das PixelSeite-Portfolio: eine fiktive minimalistische Fashion-/Lifestyle-Marke. Die "Jetzt kaufen"-Buttons sind eine reine Design-Demo — in einer echten Umsetzung würde der Bestellvorgang über ein eingebundenes Drittanbieter-Shop-Tool (z. B. Shopify oder Ecwid) laufen.

## Öffnen

Einfach `index.html` per Doppelklick im Browser öffnen — kein Build, kein Server nötig.
