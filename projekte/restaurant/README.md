# Ristorante Via Verde — Musterprojekt

Musterprojekt für das PixelSeite-Portfolio: statische Demo-Website für ein fiktives modernes
italienisches Restaurant. Kein echter Betrieb, keine echten Bilder — reine Design-Vorlage.

## Öffnen

Keine Installation nötig. Einfach `index.html` per Doppelklick im Browser öffnen, oder mit einem
lokalen Server servieren (z. B. `npx http-server .`).
