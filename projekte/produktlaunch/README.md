# NOVA — Produktlaunch (Musterprojekt)

Musterprojekt für das PixelSeite-Portfolio — eine fiktive Produkt-Landingpage für "NOVA",
ein smartes Ambiente-Lichtsystem.

## Öffnen

Einfach `index.html` per Doppelklick im Browser öffnen. Kein Build, kein Server, keine
Installation nötig — reines HTML5/CSS3/Vanilla-JS ohne externe Requests.
