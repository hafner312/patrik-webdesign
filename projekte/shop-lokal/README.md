# Kramladen Nussbaum — Musterprojekt

Musterprojekt für das PixelSeite-Portfolio: fiktiver kleiner Schweizer Laden für
handgemachte Delikatessen, Geschenke und Kunsthandwerk. Die Shop-Funktion ("In den
Warenkorb") ist nur angedeutet — ein echter Bestellvorgang würde über ein eingebundenes
Drittanbieter-Tool (z. B. Shopify oder Ecwid) laufen.

## Öffnen

Einfach `index.html` per Doppelklick im Browser öffnen — kein Build, kein Server nötig.
