# Schreinerei Bergmann — Musterprojekt

Musterprojekt für das PixelSeite Portfolio — fiktive Onepager-Webseite für eine
Schweizer Schreinerei/Möbelbau-Firma. Alle Inhalte (Firma, Adresse, Kontaktdaten)
sind frei erfunden und dienen nur der Demonstration.

## Öffnen

Kein Build, kein Server nötig — einfach `index.html` per Doppelklick im Browser öffnen.
